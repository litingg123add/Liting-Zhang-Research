# Wind Turbine Predictive Health Monitoring

## Overview

This project investigates data-driven and physics-informed approaches for wind turbine condition monitoring using SCADA operational data.

The objective is to identify abnormal operating conditions and maintenance-related events by combining machine learning methods with engineering knowledge.

## Research Questions

- How can SCADA measurements be transformed into meaningful health indicators?
- How can operating conditions be considered when detecting abnormal behavior?
- Can physics-informed features improve predictive maintenance reliability?

## Methodology

1. SCADA data preprocessing
2. Feature engineering from operational parameters
3. Health indicator construction
4. Machine learning based anomaly detection
5. Maintenance event analysis

## Planned Methods

- LSTM-based temporal modeling
- Transformer architectures
- Autoencoder anomaly detection
- Physics-informed temperature and operating models

## Dataset

The project is designed for public wind turbine SCADA datasets containing operational measurements, environmental variables, and maintenance information.

## Status

Research prototype under development.
