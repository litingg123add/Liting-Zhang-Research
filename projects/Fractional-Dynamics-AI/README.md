# Fractional Dynamics Learning with Artificial Intelligence

## Overview

This project explores artificial intelligence methods for modeling and predicting nonlinear fractional-order dynamical systems.

The research combines nonlinear dynamics analysis with scientific machine learning approaches.

## Research Topics

- Fractional-order differential systems
- Bifurcation and chaotic behavior analysis
- Data-driven dynamical modeling
- Physics-informed neural networks
- Neural operators for complex systems

## Methodology

- Numerical simulation of fractional systems
- Dynamical analysis using Lyapunov indicators and phase portraits
- AI-based prediction models
- Physics-guided learning strategies

## Status

Research framework under development.
